# Mohammed Aljami — Résumé Website

A responsive, print-friendly personal résumé website built with plain HTML and CSS.

## Run locally

Open `index.html` in a browser. There is no build step or external runtime dependency.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and select the `main` branch and `/ (root)` as the publishing source. The site uses relative asset paths so it can be served from a project page.

## Customize

Update the contact details and portfolio links in `index.html`. Keep experience, education, and skills factual and current. Use the browser's print dialog to save a PDF.
